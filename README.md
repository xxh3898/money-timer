# Money Timer

![Money Timer 아이콘](public/money-timer-logo-128.png)

Money Timer는 현재 급여 주기에서 지금까지 번 돈을 실시간으로 보여주는 무료 local-only 공개 베타입니다.

[웹에서 Money Timer 사용하기](https://money-timer-ruddy.vercel.app)

계정 가입이나 서버 전송 없이 브라우저 또는 VS Code 안에 설정을 저장합니다. 세금과 공제액은 추정하지 않으며 사용자가 입력한 실제 수령액을 기준으로 계산합니다.

## 주요 기능

- 연 실수령액, 월 실수령액, 실수령 시급 기준으로 현재까지 번 돈을 계산합니다.
- 24시간 기준 또는 근무시간 기준으로 누적 방식을 선택할 수 있습니다.
- 급여일, 지급 기준 시간, 근무 요일, 근무 시간, 휴식시간 제외 여부를 설정할 수 있습니다.
- 오늘 번 돈, 이번 급여 주기에서 번 돈, 다음 급여일까지 남은 시간, 진행률을 표시합니다.
- 목표 금액까지 남은 금액과 예상 시간을 확인할 수 있습니다.
- 소비 금액을 현재 수익 기준의 노동시간으로 환산할 수 있습니다.
- 프라이버시 모드와 라이트/다크/시스템 테마를 제공합니다.

## 웹에서 사용하기

1. [Money Timer 웹앱](https://money-timer-ruddy.vercel.app)을 엽니다.
2. 설정 화면에서 급여 기준과 실제 수령액을 입력합니다.
3. 급여일과 돈이 증가하는 방식을 선택합니다.
4. 필요하면 근무시간, 휴식시간, 프라이버시 모드와 목표 금액을 설정합니다.

설정은 현재 브라우저에만 저장됩니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저나 기기로 이동하면 설정이 유지되지 않을 수 있습니다.

## VS Code 확장

VS Code에서도 Status Bar를 통해 현재까지 번 돈과 급여 주기 진행 상황을 확인할 수 있습니다.

1. VS Code에서 Extensions 화면을 엽니다.
2. `Money Timer`를 검색합니다.
3. publisher가 `xxh3898`인지 확인하고 설치합니다.
4. Command Palette에서 `Money Timer: Configure`를 실행합니다.

확장 기능과 설정 방법은 [Money Timer for VS Code 안내](extensions/vscode/README.md)를 참고하세요.

## 데이터와 개인정보

- 웹 설정과 목표는 현재 브라우저에만 저장합니다.
- VS Code 확장 설정과 목표는 VS Code 내부 로컬 저장소에 저장합니다.
- 서버, 계정, 외부 동기화, 결제, 텔레메트리를 사용하지 않습니다.
- 프라이버시 모드를 켜면 화면에 표시되는 금액을 가립니다.

## 계산 기준

- 실제로 받는 연·월·시급을 입력해야 합니다.
- Money Timer는 세금, 공제, 상여, 수당을 계산하거나 검증하지 않습니다.
- 중복되거나 겹치거나 맞닿은 휴식시간은 하나로 합쳐 한 번만 제외합니다.
- 계산 결과는 개인 생산성 참고용이며 급여 명세서나 법적 근거로 사용할 수 없습니다.
