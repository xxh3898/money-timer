# Change Log

Money Timer VS Code 확장의 주요 변경 내역을 기록합니다.

## [0.3.0] - 2026-07-21

- 급여 입력을 실제 수령액 기준으로 변경했습니다.
- legacy `gross` 설정을 versioned migration으로 한 번만 이전합니다.
- 중복되거나 겹치거나 맞닿은 휴식시간을 한 번만 차감합니다.
- Marketplace 아이콘, 라이선스, 공개 저장소와 지원 정보를 추가했습니다.
- 불필요한 테스트 파일이 VSIX에 포함되지 않도록 패키지 범위를 정리했습니다.

## [0.2.0] - 2026-06-29

- 웹앱 계산 코어와 VS Code 확장 코어를 동기화했습니다.
- 목표 관리와 소비 노동시간 계산 명령을 추가했습니다.
- 프라이버시 모드와 휴식시간 제외 설정을 반영했습니다.
